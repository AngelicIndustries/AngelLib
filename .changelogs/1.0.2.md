## AngelLib 1.0.2

- AngelLib clients now mark their server list pings with port 0 in the handshake instead of a suffix on the hostname. Relays that route by hostname, such as e4mc, refused the suffix, so AngelLib clients saw every e4mc world as "Unknown server". Servers still recognize the suffix from older clients.
- Fixed the extra server list data meant for an AngelLib client, such as Wawel Auth's, going out with every later ping of the server.
