## AngelLib 1.0.4

- New `FileUtil.pickSaveFile` asks where to save a file with the native dialog, as `pickFile` does for opening one, and adds the extension when the name typed has none.
- Automated tests can answer the next file or save dialog by setting the system property `angellib.filePicker.next` to a path.
- New `ApngUtil` reads animated PNGs (APNG) into the same frames and delays as GIFs and animated WebP, optionally scaled down while reading so large ones never hold every frame at full size, and writes them, storing only what changed between frames, from an array or one frame at a time.
- Animated server icons can be APNG: a `server-icon.apng`, or an animated `server-icon.png`, which stays the static icon for clients without AngelLib. A `server-icon.gif` still comes first.
