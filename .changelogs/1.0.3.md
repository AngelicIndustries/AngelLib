## AngelLib 1.0.3

- Animated server icons are no longer decoded with Java's own Base64 decoder, which Java 17.0.6 and later run as faulty machine code on processors with AVX-512 VBMI (CVE-2026-114938, "Java4Shell"). Any server in the server list sends its icon, so it is decoded in plain Java now. This doesn't protect other mods or Java itself: update Java, or start it with `-XX:-UseBASE64Intrinsics`.
