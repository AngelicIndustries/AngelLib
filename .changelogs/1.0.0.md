## AngelLib 1.0.0

FentLib is now AngelLib, part of Angelic Industries.

- **Breaking:** Java packages are now `industries.angelic.angellib`; the mod ID and resource/config namespaces are `angellib`. Update all dependent mods together.
- Maven coordinates: `industries.angelic.angellib:AngelLib:1.0.0` (`dev` classifier for development).
- Updated logos, animated Catalogue background, project links, and publishing infrastructure.
- Both the ordinary and CurseForge variants use the new identity.
- Development launches use Angelica 2.2.31 to fix its glint mixin validation crash.

Existing FentLib configurations, integrations, and network payloads are not migrated automatically. Historical FentLib releases remain available.
